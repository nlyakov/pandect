# Pandect

Плъгин за Claude за работа с българското право: конекторът Pandect MCP и три умения за документите.

## Конекторът Pandect MCP

Свързва Claude с Pandect: нормите по членове, съдебната практика, институциите — и делата ти от Кантора, ако профилът
ти я има. При първото ползване Claude отваря вход в **login.lyakov.bg** — влизаш със своя профил. Какво виждаш, зависи от
правата му: **Pandect MCP · Node** (нормите, практиката, институциите) и **Pandect MCP · Case** (делата).

Нямаш профил — подай заявка за достъп на **node.lyakov.bg**.

## Уменията

**pandect-markitdown** — до всеки `.pdf` и `.docx` в папката слага `.md` със същото име и чете него. Документите с
текстов слой минават веднага; сканираните се разчитат визуално, с правила за български съдебни и административни
документи.

**pandect-document-render** — изготвя молба, жалба, сигнал или становище: взима нормите и практиката от Pandect,
минава през правилата за български език и сглобява готов `.docx` по задължителния формат.

**pandect-writing-quality** — правилата за естествен български: без дословно преведени изрази от английски и без
буквален преводачески стил, с проверена правна терминология. Важат за всеки по-дълъг текст на български, не само за документите.

## Слагане

**В приложението Claude (и в Cowork):** добави маркетплейса https://github.com/nlyakov/pandect, после **Install** на Pandect
и **Connect** на конектора.

**В Claude Code:**

```
/plugin install pandect --marketplace nlyakov/pandect
```

## Обновяване

Новите версии излизат в същия маркетплейс. В приложението плъгинът се обновява от страницата си. В Claude Code:

```
claude plugin marketplace update pandect
claude plugin update pandect@pandect
```

и Claude Code се пуска наново.
